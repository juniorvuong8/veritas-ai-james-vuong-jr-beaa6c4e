# LLM evaluation results

> We use a pretrained LLM to generate contextual dialogues with target vocabulary. Our baseline substitutes English vocabulary into fixed Vietnamese dialogues using a dictionary. On the same 24 test cases, the baseline achieved 13% and the LLM achieved 100%. The LLM passed every case, so this test set does not show where it fails (see Limits).

**Score:** the share of test cases where a native Vietnamese speaker answered "yes" to both questions:
1. *Is every English word used in the right sense for this situation?*
2. *Does the Vietnamese read naturally, like something a person would actually say?*

| | Baseline | LLM |
|---|---|---|
| **Headline (both yes)** | **13%** | **100%** |
| Words used correctly (Q1) | 96% | 100% |
| Natural Vietnamese (Q2) | 17% | 100% |
| Passes the app's structure checks | 100% | 100% |
| Level 1 | 13% | 100% |

| Level 3 | 13% | 100% |

The LLM produced a valid lesson for every case.

## How it was measured

- **Test cases** (`eval/cases.json`): 4 places × 3 levels × 2 word sets. Each place has one set of 3 suggested words and one set of 4 words that includes a word typed in Vietnamese. Cases were fixed before any dialogue was generated.
- **Baseline** (`eval/baseline/`): a bilingual dictionary plus fixed dialogue lines: an opening and closing per place, and one ready-made example line for each suggested word. A case's dialogue is those lines stitched together.
- **LLM** (`eval/results/llm.json`): generated by the app's own lesson code (`src/shared/generate.ts`), with the same prompt, model, settings, checks and single retry as the live app.
- **Rating** (`eval/ratings.json`): every dialogue rated by a native speaker on a page that shows one dialogue at a time, shuffled with a fixed seed, with no method name, title or badge.

**Limits:**
- One rater, who is also the developer.
- The rating is shuffled and unlabelled but **not fully blind**: the two methods can be told apart by length and turn-taking (the baseline's lines are stitched together, so the same speaker often talks twice in a row), and the baseline's fixed lines repeat across cases.
- 24 cases is a small sample, and every Vietnamese input in the test set maps to a word the baseline has a ready-made line for, which favours the baseline.
- Three LLM cases failed the app's checks on the first attempt and passed on the app's automatic retry, as they would for a real player.

## Rater notes on dialogues that failed

- Baseline `cafe-A-L1`: what each person say is not related to what the other person just said.
- Baseline `cafe-A-L2`: what each person say is not related to egat the other person just said.
- Baseline `cafe-A-L3`: “Is that for here or to go?“ does not go with “ Can I get a free refill?“
- Baseline `cafe-B-L1`: customer made three different request without seeing the employee respond.
- Baseline `cafe-B-L2`: customer made three different request without seeing the employee respond
- Baseline `cafe-B-L3`: Customer asks several different questions without waiting for an answer.
- Baseline `supermarket-A-L1`: customer asked three question in a row without waiting for an answer
- Baseline `supermarket-A-L2`: Customer asks several different questions without waiting for an answer
- Baseline `supermarket-A-L3`: Customer asks several different questions without waiting for an answer.
- Baseline `supermarket-B-L1`: “Chị có cần bag không ạ?” immediately followed “Dạ, cảm ơn chị. Hẹn gặp lại!” which is completely unrelated.
- Baseline `supermarket-B-L2`: what each person say is not related to what the other person just said.
- Baseline `taxi-A-L1`: “ Dạ, tới nơi rồi. Chúc chị một ngày vui!” is not right answer to “Anh ơi, fare hết bao nhiêu?”
- Baseline `taxi-A-L2`: Asked way too many questions without waiting for an answer.
- Baseline `taxi-A-L3`: “ Here we are. Have a good day!” did not answer the question.
- Baseline `taxi-B-L1`: driver didn’t say thank you to the tips bit said “Dạ, tới nơi rồi. Chúc chị một ngày vui!”
- Baseline `taxi-B-L2`: “This is a tip for you, anh.” not right answer
- Baseline `taxi-B-L3`: “This is a tip for you.“ that’s not answer the request to put on the seatbelt.
- Baseline `clinic-A-L1`: “Tôi có appointment lúc 9 giờ.“ does not answer question before it.
- Baseline `clinic-A-L2`: “I have an appointment lúc 9 giờ.” was not answer to “ Chào anh, anh thấy trong người thế nào?”
- Baseline `clinic-A-L3`: Each person says two things that are unrelated and also not related to what the other persons say.

## Rerun

```bash
npm run eval:baseline   # free: rebuild the baseline dialogues
npm run eval:llm        # paid (~$2–4): regenerate the LLM dialogues (needs ANTHROPIC_API_KEY in supabase/.env)
npm run dev             # then open /eval.html to rate, and save ratings.json into eval/
npm run eval:score      # recompute this file
```
