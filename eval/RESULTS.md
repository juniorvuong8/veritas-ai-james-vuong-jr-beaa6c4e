# LLM evaluation results

> We use a pretrained LLM to generate contextual dialogues with target vocabulary. Our baseline substitutes English vocabulary into fixed Vietnamese dialogues using a dictionary. On the same 30 test cases, the baseline achieved 10% and the LLM achieved 97%. The LLM failed 1 case(s); the rater's notes on each are below.

**Score:** the share of test cases where a native Vietnamese speaker answered "yes" to both questions:
1. *Is every English word used in the right sense for this situation?*
2. *Does the Vietnamese read naturally, like something a person would actually say?*

| Words used correctly (Q1) | 97% | 100% |
| Natural Vietnamese (Q2) | 13% | 97% |
| Passes the app's structure checks | 100% | 100% |

The LLM produced a valid lesson for every case.

## How it was measured

- **Test cases** (`eval/cases.json`): 24 planned cases (4 places × 3 levels × 2 word sets; each place has one set of 3 suggested words and one set of 4 words that includes a word typed in Vietnamese), fixed before any dialogue was generated, plus 6 extra cases (set X, one or two per place, all levels). 2 of the extra cases were chosen because the LLM had already failed that way in the rule tests (`eval/extra/RESULTS.md` has the reasons and the set's own score).
- **Baseline** (`eval/baseline/`): a bilingual dictionary plus fixed dialogue lines: an opening and closing per place, and one ready-made example line for each suggested word. A case's dialogue is those lines stitched together.
- **LLM** (`eval/results/llm.json`): generated by the app's own lesson code (`src/shared/generate.ts`), with the same prompt, model, settings, checks and single retry as the live app (the 6 extra cases were generated through the live app itself).
- **Rating** (`eval/ratings.json`): every dialogue rated by a native speaker on a page that shows one dialogue at a time, shuffled with a fixed seed, with no method name, title or badge.

**Limits:**
- One rater, who is also the developer.
- The rating is shuffled and unlabelled but **not fully blind**: the two methods can be told apart by length and turn-taking (the baseline's lines are stitched together, so the same speaker often talks twice in a row), and the baseline's fixed lines repeat across cases.
- 30 cases is a small sample, and every Vietnamese input in the test set maps to a word the baseline has a ready-made line for, which favours the baseline.
- Three LLM cases failed the app's checks on the first attempt and passed on the app's automatic retry, as they would for a real player.

```bash
npm run dev             # then open /eval.html to rate, and save ratings.json into eval/
npm run eval:score      # recompute this file
```
